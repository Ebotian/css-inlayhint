# Fixtures

This directory contains CSS samples copied from the cloned `learning-CSS` repository from [https://github.com/shehza-d/learning-CSS.git]

They are used as local, repository-owned test inputs so the test suite does not depend on the external clone at runtime.

## Source map

- `flex.style.css` was copied from `learning-CSS/flex/style.css`
- `button-hover.style2.css` was copied from `learning-CSS/CSS/button hover/style2.css`
- `Notes.css` was copied from `learning-CSS/Notes.css`

## Notes

- The files are kept intentionally small and representative rather than exhaustive.
- If the upstream samples change, update these fixtures manually so the tests remain stable and self-contained.
